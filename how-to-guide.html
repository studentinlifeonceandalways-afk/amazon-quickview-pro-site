💰 How the Profit Calculator Works

The extension calculates real profit using your custom cost inputs - not just revenue

📐 The Profit Formula

Revenue = Price × Quantity
Total Fees = (Referral Fee × Qty) + (FBA Fee × Qty) + Storage Fee + Additional Costs
Total Costs = (COGS × Qty) + (Shipping × Qty) + (Ads × Qty) + (Revenue × Return Rate %)
Net Profit = Revenue - Total Fees - Total Costs
Margin = (Net Profit / Revenue) × 100%
ROI = (Net Profit / Total Costs) × 100%
💡 Key Insight: The calculator multiplies ALL costs by the Quantity setting. Set Quantity=2 for a 2-pack product, and everything scales automatically!

⚙️ Settings You Control (Per Profile)

📦 Product Cost (COGS) - Your cost to buy/manufacture
🚚 Shipping to Amazon - Cost to send inventory to FBA
📢 PPC Ads Cost - Estimated advertising per unit
🔄 Return Rate (%) - Estimated product returns
🏪 Storage Fee - Monthly storage per unit
📬 FBA Fee - Amazon's fulfillment fee
📊 Referral Fee (%) - Amazon's commission (customizable!)
🔢 Quantity - Units per sale (multiplies all costs)
⚠️ Important: Amazon's referral fees vary by category! Electronics = 8%, Clothing = 17%, Most categories = 15%. Always set the correct percentage for accurate profit calculations.

📁 Organize with Categories (Two-Way Sync)

Categories work BOTH ways - add profiles to categories OR add categories to profiles

📌 Method 1: Add Categories to a Profile

🎯 When to use this: When editing a profile, you want to assign it to existing categories.
1
Click ✏️ Edit on any profile card
2
Scroll to the 🏷️ Categories section in the modal
3
Check the boxes next to categories you want to assign
4
Click Save Profile - category chips appear on the profile card!
💡 Result: The profile appears in the Categories tab under each selected category, and category chips show on the profile card.

📌 Method 2: Add Profiles to a Category

🎯 When to use this: When viewing a category, you want to add multiple profiles at once.
1
Go to the Categories tab in sidebar
2
Click + Add Profiles on any category
3
Search and select profiles to add (checkboxes)
4
Click Add to Category - profiles are now linked!
💡 Result: All selected profiles now show this category chip and appear in the category's profile list.
🔄 Real Example: Two-Way Sync in Action

Scenario: You create a category called "🏆 High Margin (>30%)"

Option A: Edit the "Electronics" profile → Check "High Margin" box → Profile now shows the category chip
Option B: Go to Categories tab → Click "+ Add Profiles" on "High Margin" → Select "Electronics" → Same result!

✨ Either way works! The relationship is bidirectional and automatically syncs.

🔧 Step-by-Step Setup Guide

Get accurate profit calculations in 5 minutes
1

Create a Research Profile

In the sidebar, click "New Product Profile". Give it a name like "Electronics Sourcing" and select your Amazon domain (amazon.com for US, amazon.co.uk for UK, etc.).

2

Enter Your Costs

Fill in your actual numbers:

  • Product Cost (COGS): What you pay your supplier
  • Shipping to Amazon: Freight cost per unit
  • FBA Fee: Use Amazon's FBA Revenue Calculator to find this
  • Referral Fee %: 15% for most, 8% for electronics, 17% for clothing
  • Quantity: Set to number of units per pack (e.g., 2 for a 2-pack)
3

Add Additional Costs (Click the + button)

Many sellers forget these hidden fees:

  • 🇺🇸 Media Closing Fee: $1.80 for books/DVDs (Fixed cost)
  • 🌍 Digital Service Tax: 2-3% for EU/UK sales (Percentage cost)
  • 🔧 Prep/Inspection Fee: If using a 3PL service
  • 📦 Packaging/Insert Costs: Custom boxes, thank you cards
4

Assign Categories (Optional but Recommended)

In the profile modal, scroll to the Categories section and check boxes for relevant categories. Or go to Categories tab → "+ Add Profiles" to add this profile later.

5

Set as Active Profile

Click the checkbox or "Set as Active Profile" button. This profile will now be used for all badge calculations on Amazon pages.

6

Start Researching & Bookmarking!

Browse Amazon - badges will appear showing profit calculated with YOUR costs. Click ★ to bookmark products to your profile for later analysis.

⚠️ Common Mistakes to Avoid:
  • Wrong Referral Fee % - Electronics are 8%, NOT 15%!
  • Forgetting Minimum Fees - US charges min $0.30, UK min £0.25, etc. The extension handles this automatically!
  • Missing Media Closing Fees - Add $1.80 as Additional Cost for books/DVDs
  • Wrong Quantity Setting - A 3-pack priced at $30 should have Quantity=3, not Quantity=1 with $30 price
  • Not Using Categories - Categories help you track performance across product types and make better decisions!
💡 Pro Tips for Maximum Accuracy:
  • 📬 FBA Fee: Always check Amazon's FBA Revenue Calculator for your product's exact size tier
  • 📊 Referral Fee: Look up your category in Amazon's Referral Fee Schedule
  • 📦 Quantity Setting: If you sell a 2-pack for $19.99, set Quantity=2 and Price=$19.99 (the calculator divides price per unit automatically)
  • 🌍 Multiple Marketplaces: Create separate profiles for each domain (amazon.com vs amazon.co.uk) with correct FBA fees for each
  • 🏷️ Categories: Create categories for different sourcing strategies and use the dashboard to compare performance
  • 🔄 Update Bookmarks: Use the Update Bookmark feature weekly to keep profit calculations current with changing prices/BSR
